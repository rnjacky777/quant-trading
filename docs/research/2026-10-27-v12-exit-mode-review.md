# V10 → V12：以追蹤與訊號退出取代固定止盈

V10→V12只改exit_mode=fixed→signal：停用固定15%止盈，保留原始5%止損、收盤5%啟動／5%距離追蹤、訊號退出、SMA24/180、1%進場門檻、0.5%風險、1倍槓桿和原訊號重置。沒有採用失敗的V11突破重入。全部14筆來源比較已保存。2024完整年收益2.61%→3.16%、Sharpe1.384→1.523、回撤-1.18%→-1.40%；2025完整年收益0.77%→0.91%、Sharpe0.420→0.477、回撤-1.68%→-1.74%。長區間收益12.99%→13.54%、Sharpe0.978→0.993、交易63→49、費用131.23→102.20 USDT，但回撤-2.81%→-2.86%。雙倍成本下長區間9.81%→11.32%、2024年2.22%→2.81%、2025年0.48%→0.66%。早期2020–2022及2026年部分結果退步，不宣稱全面穩定改善；V12是收益及成本效率改善候選，最大回撤略增，仍需未見驗證。110項是既有程式測試，本輪未新增單元測試或程式功能，只用既有功能做一組策略變更。報告docs/research/2026-10-27-v12-exit-mode-review.md。

## 為什麼有110項測試

110項是已有程式的自動化檢查，不是110組策略參數或110次獨立策略驗證。包括訊號延遲、止損價格、跳空、避免未來資料、版本保存、重現與dashboard固定設定等。本輪沒有新增程式功能或測試項目，也沒有重跑整套pytest；使用既有exit_mode功能，只測一組策略設定變更，並核對14筆候選快照可精確重現。14筆既有回測包含重疊／重複時段，不當14次獨立驗證。

## 診斷後保留與排除的方向

V11長區間新增進場的事後分組顯示，不是所有後續重入都壞；簡單限制重入次數沒有支持。V10慢均線上升與未上升的原交易組都曾淨獲利，也沒有直接加上斜率限制的證據。這些僅為診斷，不是額外掃描策略或可加總的因果效果。

V10長區間14次固定止盈皆下一根買回。續單原本也淨盈利（9贏、5輸，合計約540.66 USDT），因此不能先宣稱這種切換必然有害。本輪固定假設：取消固定目標後，既有追蹤止損仍保護部位，可能減少切換並保留較長趨勢。試驗結果而非假設本身決定是否有改善。

## 單一變更

`exit_mode`: `fixed` → `signal`。仍由SELL訊號、初始保護止損、追蹤止損及區間結束退出。保留5%／5%追蹤、原始5%止損、SMA24/180、1%門檻、0.5%單筆風險、1倍槓桿及原先訊號重置。固定止盈欄位15%為保存的原數值，但signal模式不執行，實際成交紀錄take_profit_price皆為None，沒有固定止盈退出。V12直接來自V10，沒有繼承未通過的V11。

## 採用判斷

V12在2024、2025完整曆年與長區間的收益及Sharpe較高，交易數與費用下降，雙倍成本下相同三段收益也較高，值得保留為研究候選。但最大回撤略增，所以不宣稱全面提高穩定性。早期2020–2022區間收益3.88%→2.64%、回撤略增，2026-01-01至10-20收益0.71%→0.69%，也有反例。

收益更高與所有風險都更低是不同要求；Sharpe略增但最大回撤略大屬取捨。保留V10作對照，不提高本金風險或槓桿來美化收益，不把最新版本自動視為採用通過。

所有資料已在多輪參數選擇中使用，不能聲稱未見或統計獨立驗證。只研究BTC現貨，不能外推其他幣存活偏差。引擎僅用已完成K線、下一根成交／生效，仍未用真實訂單簿確認流動性容量和跳空成交品質；雙倍固定成本無法代替這些檢查。未啟用實盤。
